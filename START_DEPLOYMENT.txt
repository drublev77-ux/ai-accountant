┌─────────────────────────────────────────────────────────┐
│  СПОСОБ 1: АВТОМАТИЧЕСКИЙ СКРИПТ (РЕКОМЕНДУЕТСЯ)        │
└─────────────────────────────────────────────────────────┘

    ./quick-github-deploy.sh

    ✓ Запросит ваш GitHub username
    ✓ Запросит имя репозитория
    ✓ Автоматически настроит конфигурацию
    ✓ Отправит код на GitHub
    ✓ Покажет следующие шаги


┌─────────────────────────────────────────────────────────┐
│  СПОСОБ 2: ВРУЧНУЮ (3 ШАГА)                             │
└─────────────────────────────────────────────────────────┘

    1. Создайте репозиторий на GitHub:
       https://github.com/new

    2. Отправьте код:
       git add .
       git commit -m "Initial commit"
       git remote add origin https://github.com/YOUR_USERNAME/vite-template.git
       git push -u origin main

    3. Включите GitHub Pages:
       Settings → Pages → Source: GitHub Actions → Save

┌─────────────────────────────────────────────────────────┐
│  ПОСЛЕ ДЕПЛОЯ                                           │

    Ваш сайт будет доступен:
    https://YOUR_USERNAME.github.io/vite-template/

    Проверьте деплой:
    - Откройте вкладку "Actions" на GitHub
    - Дождитесь зеленой галочки ✅ (2-3 минуты)
    - Откройте ваш сайт

    Каждый git push автоматически обновляет сайт:

    git add .
    git commit -m "Update features"
    git push

    → GitHub автоматически пересобирает и деплоит!

└─────────────────────────────────────────────────────────┘

    ❌ 404 при переходе на сайт:
       → Settings → Pages → Source: GitHub Actions

    ❌ Workflow не запускается:
       → Settings → Actions → Workflow permissions
       → Read and write permissions

    ❌ Authentication failed при push:
       → Используйте Personal Access Token (не пароль)
       → https://github.com/settings/tokens
